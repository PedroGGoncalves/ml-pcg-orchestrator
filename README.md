# Research Projects – M.Sc. Research

This repository contains different projects developed as part of my M.Sc. research, which focuses on **content adaptation with player profiles**.

## About

The projects gathered here are related to my master's research area, exploring how content can be adapted based on player profiles. Each project addresses a different aspect of this topic and may include experiments, prototypes, and supporting code.

## Projects

Each folder in this repository corresponds to a distinct project developed during the research. Please refer to the individual project folders for more details, instructions, and documentation.
